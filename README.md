# Han An Hua Foundation Website

Website statis ini sudah siap dipublikasikan melalui GitHub Pages.

## Cara upload

1. Buat repository baru di GitHub, misalnya `han-an-hua-foundation`.
2. Ekstrak file ZIP.
3. Upload **semua isi di dalam folder** ke halaman utama repository. Pastikan `index.html` berada di root repository.
4. Buka **Settings > Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
7. Tunggu beberapa menit sampai alamat website muncul.

## Isi website

- Program magang mahasiswa aktif
- Jalur pendidikan siswa sekolah menengah
- Bidang studi dan posisi magang
- Contoh hotel dan resort dalam jejaring program
- Dokumentasi kegiatan
- WhatsApp khusus kerja sama institusi
- Google Maps

Website tidak menampilkan biaya, proses internal, nama sekolah mitra, atau identitas pihak lain yang tidak diperlukan.
