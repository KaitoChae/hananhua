# Yayasan Han An Hua — GitHub Pages V9

Perubahan versi ini:
- Foto direktur diganti dengan foto terbaru.
- Animasi ringan diaktifkan untuk Chrome, Safari, Firefox, Samsung Internet, dan browser HP lainnya.
- Animasi hanya memakai transform dan opacity agar tetap ringan.
- File CSS/JS diganti ke V9 agar browser tidak menggunakan cache lama.

## Upload ke GitHub
1. Ekstrak ZIP.
2. Timpa semua file lama di root repository.
3. Pastikan `index.html`, `404.html`, `styles-v9.css`, `script-v9.js`, `i18n-v9.js`, `.nojekyll`, dan folder `assets` berada di root.
4. Setelah deployment selesai, buka `https://kaitochae.github.io/hananhua/?v=9`.
