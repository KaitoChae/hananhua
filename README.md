## Cara mengunggah
1. Ekstrak ZIP.
2. Unggah seluruh isi hasil ekstrak langsung ke root repository.
3. Pastikan `index.html`, `404.html`, `styles.css`, `script.js`, `i18n.js`, `.nojekyll`, dan folder `assets` berada di root.
4. Buka GitHub **Settings → Pages**.
5. Pilih **Deploy from a branch**, branch **main**, folder **/(root)**.
6. Klik **Save** dan tunggu sekitar 1–5 menit.

Jangan mengunggah ZIP tanpa mengekstraknya.
